# Project commenting preference

- Put a short, plain-language file-purpose comment at the top of each Python file.
- Put a plain-language comment above every function and method explaining what it does.
- Place the comment above decorators when present. Keep useful existing docstrings.
- Follow this style for future work and update comments when behavior changes.
- Keep code as simple as practical: small functions, direct logic, and no unnecessary frameworks or abstractions.
